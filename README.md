# うまアプリ（JRA 馬券収支シミュレーター）

「2026年1月〜現在まで、ルメール騎手の全騎乗を単勝100円ずつ買っていたら収支はいくら？」のような計算をするローカル Web アプリです。

- データ元: JRA 公式サイト（www.jra.go.jp の「過去レース結果」：着順・人気・払戻金）
- 検索時に、指定期間で未取得の開催だけを自動で取得してから計算します（差分更新）
- データはローカルの SQLite（`data/jra.sqlite`）に保存されます

## 起動

Node.js 22.13 以上（推奨 24）が必要です。

```bash
npm install
```

```bash
npm start
```

ブラウザで http://localhost:3939 を開きます。

JRA 公式サイトは 1 開催（1 日・1 場）の全 12 レースの結果と払戻が 1 ページにまとまっているため、2026 年分（約 250 開催・3,300 レース）でも約 500 回のアクセスで取得できます。サーバーへの負荷を避けるため 2.5 秒に 1 回程度のアクセスにしているので、初回は 20〜30 分ほどかかります。一時的にアクセス制限（HTTP 503 など）を受けた場合は、自動で数分〜30 分待ってから再開します。取得中も、取得済みの分で途中経過を表示します。2 回目以降は新しい開催の分だけを取得します。

ターミナルからまとめて取得しておくこともできます。

```bash
npm run sync -- 2026-01-01 2026-11-19
```

## できること

- 対象: 騎手 / 調教師 / 馬（名前の部分一致。同名候補が複数あれば選択）
- 期間: 任意の開始日〜終了日
- 券種: 単勝 / 複勝、1 レースあたりの購入額
- 結果: 収支・回収率・的中率・着別度数・最高払戻、累積収支グラフ、月別収支（グラフ / 表）、レース一覧

## 計算ルール

- 払戻は JRA 公式の払戻金（100 円あたり）を使用（同着の払戻も正しく反映）
- 出走取消・競走除外は返還のため購入数に含めない
- 競走中止・失格はハズレ扱い
- JRA 10 場のレースのみ（地方・海外は含まない）
- 公式の成績表には単勝オッズの列が無いため、レース一覧のオッズは勝ち馬のみ（払戻金 ÷ 100）表示

## 仕組み

JRA のページは URL ではなく `cname`（末尾に 2 桁のチェック値付き）を POST して開く仕組みなので、URL を組み立てずにページ内のリンクを辿ります。

1. 月別の開催一覧（当月 → 「前月」リンクを辿って過去の月へ）
2. 開催ごとのレース選択ページ → 全レース結果ページへのリンク
3. 全レース結果ページ（12 レース分の着順・騎手・調教師・人気・払戻金）

## 注意

JRA 公式サイトのデータを個人的に利用するためのツールです。取得データの再配布や、短い間隔での大量アクセスは行わないでください。アクセス間隔は環境変数 `UMAAPP_INTERVAL_MS`（既定 2500ms）で変更できます。

ノートン等のセキュリティソフトが HTTPS 通信を検査している環境向けに、起動スクリプトで `--use-system-ca`（Windows の証明書ストアを利用）を指定しています。

## 構成

| `src/query.js` | 収支計算 |
